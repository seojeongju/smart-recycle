# 5차 구현

**프로젝트:** smart-recycle (Smart Recycle)  
**기간:** 2026-10-05  
**상태:** 코드 반영. 배포는 요청 시  
**관련 문서:** [4차 구현.md](./4차%20구현.md)

4차 데이터를 연결해 **오늘 버려도 되는지**를 분명히 하고, 시연·현장 체크를 보탠다.

한 줄: **배출일 힌트 → 동네 추천 → 시연 샘플 → 가방 체크 → 지도 제보 경고**.

---

## 1. 배출일 ↔ 가이드·가방

- 가이드와 오늘 가방에 `collection` 힌트
- 오늘이면 강조, 아니면 다음 요일, 전용함은 아무 때나
- 동네가 없으면 마이로 유도

## 2. 동네 자동 추천

- 위치와 역지오코딩으로 `○○구`를 맞추고 확인만 받음
- 홈·마이에 배너

## 3. 시연 샘플

- 홈의 페트·약·배달용기 미리보기
- `GET /api/demo/recognize?item=` — 실제 촬영 없이 확인 화면까지

## 4. 가방 체크 · 지도 제보

- 가져간 품목은 기기 `localStorage`에 표시
- 24시간 제보가 있으면 목록 문구와 주황 마커
