# 2차 구현

**프로젝트:** smart-recycle (Smart Recycle)  
**기간:** 2026-09-01  
**상태:** 코드 반영. 배포·시크릿·R2 수명 규칙은 아래 체크리스트 참고  
**관련 문서:** [PRD.md](./PRD.md), [1차 구현.md](./1차%20구현.md)

1차 루프(촬영→가이드→인증→지도)는 유지하고, **인식 품질**과 **실패 시 검색**, **수거함 실데이터**, **배포·이미지 수명**을 보강한다.

---

## 1. 인식 2차 분류

파이프라인:

1. DETR(`@cf/facebook/detr-resnet-50`)로 객체 힌트  
2. Qwen(`@cf/qwen/qwen3.8-27b`)이 카탈로그 `item_id`만 고름 (도구 호출 + JSON)  
3. 실패 시 Moondream(`@cf/moondream/moondream3.1-9B-A2B`)  
4. 그래도 실패하면 DETR 카테고리 대표 품목  
5. 최종 실패는 검색 폴백

관련 파일: `worker/recognize.ts`, `worker/vision.ts`

---

## 2. 미인식 UX

- 실패 시 유사 품목 카드 + 카테고리 칩 + 최근 검색
- 가이드 하단 **이 답이 맞나요?** → `POST /api/recognize/feedback`
- 별칭 보강: 배달 용기, 약봉지, 아이스컵 등 (`migrations/0003_phase2.sql`)

---

## 3. 공공데이터 지도

Cron(매일 03:00 KST)이 지역을 돌아가며 약국 목록을 가져와 **폐의약품 수거함**으로 upsert한다.

- API: 국립중앙의료원 전국 약국 정보 (`B552657` `getParmacyListInfoInqire`)
- 시드: 부산·인천·대구·대전·광주·수원·잠실 등 보강
- 키가 없으면 시드만 유지하고 `sync_jobs`에 기록

키 등록:

```bash
npx wrangler secret put PUBLIC_DATA_API_KEY
```

공공데이터포털에서 발급받은 **Decoding** 키를 넣는다.

---

## 4. 배포·이미지 수명

| 항목 | 방법 |
|------|------|
| GitHub Actions 배포 | `.github/workflows/deploy.yml` — 저장소 Secrets에 `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID` |
| Workers Builds | Cloudflare 대시보드에서 GitHub 저장소 Connect (선택) |
| R2 lifecycle | `npm run r2:lifecycle` (인식 7일, 인증샷 90일). **이미 프로덕션 버킷에 적용됨** |
| Cron 보조 삭제 | 매일 `uploads/` 7일 초과 객체 삭제 |

---

## 5. 추가 API

| Method | Path | 설명 |
|--------|------|------|
| POST | `/api/recognize/feedback` | `{ log_id, item_id, helpful }` |
| POST | `/api/sync` | 공공데이터 수동 동기화 (10분 1회) |
| GET | `/api/sync/status` | 마지막 동기화·약국 수거함 수 |

인식 응답에 `recognition.id`, `recognition.model`, `suggestions`가 붙는다.

---

## 6. 로컬·배포

```bash
npm run db:migrate:local
npm run db:migrate:remote
npm run r2:lifecycle
npx wrangler secret put PUBLIC_DATA_API_KEY
npm run deploy
```

GitHub Actions를 쓰려면 저장소 Secrets를 넣은 뒤 `main` 푸시.

---

## 7. 아직 수동인 것

- 공공데이터 API 키 발급·시크릿 등록 — 프로덕션 시크릿 등록 완료
- GitHub `CLOUDFLARE_*` Secrets
- `npm run r2:lifecycle` 한 번 실행 (버킷 권한 필요) — 프로덕션은 적용 완료
- 의류·소형가전 전국 API는 약국만큼 표준화가 안 되어 시드 + 이후 소스 추가
