# 4차 구현

**프로젝트:** smart-recycle (Smart Recycle)  
**기간:** 2026-10-05  
**상태:** 코드 반영. 배포는 요청 시  
**관련 문서:** [PRD.md](./PRD.md), [3차 구현.md](./3차%20구현.md)

3차 루프 위에 **습관·신뢰** 기능을 붙인다. OAuth, 푸시, 다중 품목 인식, 관리자 콘솔, 업사이클 갤러리는 이번 범위 밖이다.

한 줄: **동네 배출일 → 쌍둥이 품목 → 수거함 제보 → 주간 미션 → 퀴즈 → 함께 버리기 → 단지 메모**.

---

## 1. 우리 동네 배출일

- 서울 25개 구 시드. 요일별 카테고리(참고 일정)
- `GET /api/districts`, `GET /api/schedule`, `PATCH /api/me`에 `district_id`
- 홈 배너: 오늘·내일 배출 품목. 마이에서 구 선택·주간표

관련: `migrations/0004_phase4.sql`, `src/components/CollectionBanner.tsx`

---

## 2. 헷갈리는 쌍둥이 품목

- `item_twins` (투명/유색 페트, 종이컵/플라스틱컵, 배달용기/플라스틱, 알미늄/철캔)
- 가이드에 이유와 함께 교차 링크

관련: `worker/catalog.ts`, `src/components/GuideView.tsx`

---

## 3. 수거함 제보

- `POST /api/bins/:id/reports` (`missing` | `closed`)
- 사용자당 함·종류·KST 하루 1회
- 지도 상세에 24시간 집계와 제보 버튼

---

## 4. 주간 미션 · 5. 퀴즈

- 페트 2회 / 아무 품목 3회 / 폐의약품 1회. 주 월요일(KST) 리셋, 달성 시 보너스 P
- 날짜로 돌아가는 퀴즈 1문항. 정답 후 관련 가이드

---

## 6. 함께 버리기 · 7. 단지 메모

- 오늘 인증 품목을 특수함 → 재활용 → 음식물 → 일반 순으로 정렬
- 단지 배출함 메모는 `localStorage` (`smart-recycle_complex_note`)

---

## API

| 메서드 | 경로 | 설명 |
| --- | --- | --- |
| GET | `/api/home` | 홈 묶음(배출일·퀴즈·미션·가방) |
| GET | `/api/districts` | 구 목록 |
| GET | `/api/schedule` | 오늘·내일·주간 |
| GET / POST | `/api/missions`, `/api/missions/:id/claim` | 주간 미션 |
| GET / POST | `/api/quiz` | 퀴즈 |
| GET | `/api/bag` | 오늘 함께 버리기 |
| POST | `/api/bins/:id/reports` | 수거함 제보 |

배포 워크플로는 D1 마이그레이션을 먼저 적용한다.
