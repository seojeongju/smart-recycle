# 3차 구현

**프로젝트:** smart-recycle (Smart Recycle)  
**기간:** 2026-09-01  
**상태:** 코드 반영. 배포는 요청 시  
**관련 문서:** [PRD.md](./PRD.md), [1차 구현.md](./1차%20구현.md), [2차 구현.md](./2차%20구현.md)

2차(인식 품질·공공데이터 지도) 위에, **촬영 직후 확인 → 체크 가이드 → 인증** 루프와 지도·온보딩·마이 체감을 다듬는다.

한 줄: **촬영 → 로딩 → “이 물건 맞나요?” → 체크 가이드 → 인증**, 그다음 지도 시트, 온보딩·PWA·마이.

---

## 1. 인식 확인 루프

- 촬영·앨범 직후 썸네일과 단계 문구(사진 정리 → 품목 살펴보기 → 배출 방법)
- 매칭되면 **이 물건 맞나요?** — 맞아요 / 아니에요 / 대안 품목
- 맞아요·대안은 `POST /api/recognize/feedback` 후 가이드로 이동
- 아니에요·미인식은 기존 폴백(유사 품목·칩·최근 검색)

관련 파일: `src/pages/RecognizePage.tsx`, `src/components/RecognizeFlow.tsx`

---

## 2. 가이드 체크리스트 + 선택 인증 사진

- 단계 탭으로 체크, 진행률 표시, 세션에 저장
- 필수 단계를 다 체크해야 인증 버튼이 켜짐
- 인증 사진은 선택. `POST /api/checkins` multipart (`item_id` + `image`)
- 인식에서 들어온 경우에는 하단 “이 답이 맞나요?”를 숨김 (확인 화면과 중복)

관련 파일: `src/components/GuideView.tsx`, `src/pages/ItemPage.tsx`

---

## 3. 지도 바텀시트

- 목록·상세를 하단 시트로 표시
- 마커·목록에 출처: 약국 수거함 · 공공데이터 / 참고 위치
- GPS 역지오코딩으로 “○○ 기준 · 안내는 일반 기준이에요”
- 약국 동기화는 시·도당 최대 **5페이지**(약 1,000곳)

관련 파일: `src/pages/MapPage.tsx`, `src/lib/region.ts`, `worker/sync.ts`

---

## 4. 온보딩 · PWA · 마이

- 한국어 온보딩 3장 (촬영 / 지도 / 인증). 키 `smart-recycle_onboarded_v3`
- 홈에 설치 배너 (`beforeinstallprompt` + iOS 홈화면 안내)
- 서비스 워커 `/sw.js` 등록
- PWA PNG 아이콘 192·512 (`any` + `maskable`), iOS `apple-touch-icon.png` 180
- 마이: 포인트 지갑 카드 + 인증을 거래 내역처럼 표시

관련 파일: `src/components/Onboarding.tsx`, `src/components/InstallBanner.tsx`, `src/pages/MePage.tsx`, `public/sw.js`

---
